# Data

## Files

| File | Description |
|---|---|
| `laptops.csv` | Raw data, entered by hand, values with units (e.g. `16GB`, `1.87kg`). |
| `laptops_clean.csv` | Numeric version used by the app, generated by `python src/clean_data.py`. Do not edit by hand. |

## Sources

- Collection date: 16.11.2026
- Laptop specifications and prices: [morele.net](https://www.morele.net), collected manually.
- CPU and GPU benchmark scores: PassMark, [cpubenchmark.net](https://www.cpubenchmark.net), [videocardbenchmark.net](https://www.videocardbenchmark.net).

Prices change frequently; the results reflect the prices on the collection date.

## Columns (clean file)

| Column | Unit / meaning | Direction |
|---|---|---|
| `ID` | Short identifier (L01, L02, ...), used as the index | - |
| `Name` | Full product name as listed in the shop | - |
| `Short_name` | Short label for charts and tables | - |
| `Price` | PLN | cost (min) |
| `System` | Ordinal code: 0 = no OS, 1 = Windows 11 Home, 2 = Windows 11 Pro | benefit (max) |
| `RAM` | GB | benefit (max) |
| `Memory` | SSD capacity, GB (1 TB = 1024 GB) | benefit (max) |
| `CPU_name` | Processor model | - |
| `CPU_score` | PassMark CPU Mark (multithread rating) | benefit (max) |
| `GPU_name` | Graphics model | - |
| `GPU_score` | PassMark Average G3D Mark | benefit (max) |
| `Display` | Refresh rate, Hz | benefit (max) |
| `Battery` | Battery capacity, Wh | benefit (max) |
| `Weight` | kg | cost (min) |

## Notes

- `System` is an ordinal scale: the codes express order (Pro > Home > none), not that Pro is "twice as good" as Home.
- Battery capacity (Wh) is a proxy for battery life; actual runtime also depends on the CPU, GPU and display.
